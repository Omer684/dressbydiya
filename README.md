## Before Deploying — Update These

Open `index.html` and replace:
- `923000000000` → your sister's actual WhatsApp number (with country code, no +)
- `https://www.instagram.com/diya.clothing.pk` → already correct!

## Deploy on GitHub Pages (Free)

1. Create a GitHub account at github.com
2. Click "New Repository" → name it `dressbydiya` → Public → Create
3. Upload all files (drag & drop in browser)
4. Go to Settings → Pages → Source: main branch → Save
5. Your site is live at: `https://yourusername.github.io/dressbydiya`

## Connect Your Free Domain (GitHub Student Pack)

1. Get your free `.me` domain from Namecheap (in Student Pack)
   Or get `.com.pk` / `.pk` domain from pknic.net.pk (very cheap in Pakistan)
2. In your domain settings → add CNAME record pointing to `yourusername.github.io`
3. In GitHub repo → Settings → Pages → Custom domain → enter your domain
4. Done! Site live at `www.dressbydiya.pk` or similar

## Customize Products / Prices

The website uses WhatsApp for orders (perfect for Pakistan).
Just update the WhatsApp number and customers message directly.

To add real product photos later, replace the colored div backgrounds
in the Collections section with `<img>` tags.
